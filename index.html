Thuộc tính flex-basis trong CSS Flexbox

Thực hành thiết lập kích thước cơ sở ban đầu trên trục chính (Main Axis)

1. Lý thuyết & Cú pháp

Thuộc tính flex-basis chỉ định kích thước cơ sở ban đầu của Flex Item trên trục chính (main axis) trước khi không gian còn lại được phân phối bởi flex-grow hoặc flex-shrink.

Cú pháp: flex-wrap: number | auto | initial | inherit;
💡 Lưu ý quan trọng: Trục chính phụ thuộc vào flex-direction:
  • flex-direction: row (mặc định) → Main Axis là chiều ngang (flex-basis đóng vai trò như width ban đầu).
  • flex-direction: column → Main Axis là chiều dọc (flex-basis đóng vai trò như height ban đầu).
Ví dụ 1

Sử dụng flex-basis với đơn vị px (Main Axis chiều ngang)

Container có flex-direction: row (mặc định). Các item có kích thước cơ sở khác nhau: 200px, 100px, 150px.

Item 1 (200px)
Item 2 (100px)
Item 3 (150px)
.ex1-item1 { flex-basis: 200px; }
.ex1-item2 { flex-basis: 100px; }
.ex1-item3 { flex-basis: 150px; }
Ví dụ 2

flex-basis thay đổi theo flex-direction: column (Main Axis chiều dọc)

Khi flex-direction: column, trục chính là chiều dọc nên flex-basis: 100px xác định chiều cao cơ sở của từng phần tử.

Item 1 (Cao 100px)
Item 2 (Cao 100px)
Item 3 (Cao 100px)
.container.ex2 {
    display: flex;
    flex-direction: column;
    height: 380px;
    gap: 10px;
}
.ex2-item {
    flex-basis: 100px; /* Xác định chiều cao cơ sở */
}
Ví dụ 3

Sử dụng flex-basis với đơn vị phần trăm (%)

Thiết lập flex-basis: 50% để mỗi Item chiếm khoảng 50% kích thước trục chính của Container (chia 2 cột đều nhau).

Item 1 (50%)
Item 2 (50%)
.ex3-item {
    flex-basis: 50%;
    box-sizing: border-box;
}
Ví dụ 4

Kết hợp flex-basis với flex-grow

Các item đều có kích thước cơ sở ban đầu là 100px, phần không gian còn dư trong container (600px) được chia theo tỷ lệ flex-grow: 1 : 2 : 1.

Item 1 (grow: 1)
Item 2 (grow: 2)
Item 3 (grow: 1)
.container.ex4 { width: 600px; }
.ex4-item1 { flex-basis: 100px; flex-grow: 1; }
.ex4-item2 { flex-basis: 100px; flex-grow: 2; /* Nhận gấp đôi khoảng trống */ }
.ex4-item3 { flex-basis: 100px; flex-grow: 1; }

5. Bảng tổng hợp các giá trị của flex-basis

Giá trị Ý nghĩa & Cách hoạt động Ví dụ thực tế
<length> (px, rem, em) Đặt kích thước cơ sở cố định theo đơn vị độ dài flex-basis: 200px;
<percentage> (%) Đặt kích thước cơ sở theo phần trăm chiều dài trục chính của Container flex-basis: 50%;
auto (Mặc định) Lấy theo thuộc tính width/height hoặc kích thước nội dung flex-basis: auto;
initial Khôi phục về giá trị mặc định của CSS (tương đương auto) flex-basis: initial;
inherit Kế thừa giá trị flex-basis từ phần tử cha flex-basis: inherit;
